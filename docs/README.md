## Conventions

- **Dates** are 2026; run ids are UTC, text times are UAE local time (UTC+4).
- **"The VM"** is the virtualised x86 server hosting the live network; in the paper it is only ever a tested environment.
- **Numbers** in the results documents are regenerated by the analysis code and come with the table they are in.
- **UK spelling**, and plain words before abbreviations.
